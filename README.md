# CS188 projects (UC Berkeley, Fall 2025)

Programming projects of UC Berkeley CS188 (Introduction to Artificial Intelligence, Fall 2025), one folder
per project. The written homework, and the notes each project applies, live in the study repository
(one coursework project per folder, `prj-cs188-<folder>`).

Course site: <https://inst.eecs.berkeley.edu/~cs188/fa25/>

| Project | Topic | Folder |
|---|---|---|
| 1 | Search in Pac-Man | [`search/`](search/) |
| 2 | Multi-agent Pac-Man | [`multiagent/`](multiagent/) |
| 3 | Reinforcement learning | [`reinforcement/`](reinforcement/) |
| 4 | Ghostbusters: Bayes nets and HMM tracking | [`tracking/`](tracking/) |
| 5 | Machine learning | [`machinelearning/`](machinelearning/) |
